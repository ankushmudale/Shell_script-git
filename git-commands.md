GIT Commands

git init - initialize git repo
git status - git status 
git add * - add all the file in git repo
git commit -m "msg" - git commit with msg
git config --global user.username <"user name">-
git config --global user.email <"user email id">- 
git remote -v : check to connected github account
git remote set-url origin <SSH URL> - Connect the remote directory using SSH key
